# 📊 Retail Sales Performance Analysis – Power BI Dashboard

## 🚀 Project Overview

This project is a complete **Retail Sales Performance Analysis Dashboard** built using **Power BI** to analyze and visualize business sales data across products, categories, regions, customers, and profitability trends.

The dashboard transforms raw retail data into meaningful business insights using interactive visualizations, KPIs, slicers, trend analysis, and performance metrics.

It helps stakeholders answer critical business questions such as:

* Which products generate the highest revenue?
* Which regions perform best in terms of sales and profit?
* Which customer segments contribute the most?
* Which products are highly profitable or loss-making?
* What are the sales and profit trends over time?
